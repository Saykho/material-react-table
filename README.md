# Time Tracker Table

Приложение для отображения отчетов по времени сотрудников в виде интерактивной таблицы.

## Возможности

- 📊 Отображение временных отчетов для 20 пользователей
- 📅 Переключение между периодами: дни, недели, месяцы
- 📈 Автоматический подсчет итогов по строкам (пользователям) и столбцам (периодам)
- 🎨 Современный UI с использованием Material-UI
- ⚡ Быстрая работа благодаря Vite

## Технологии

- **React 18** с TypeScript
- **Vite** для быстрой разработки
- **Material-React-Table** для отображения данных
- **Material-UI** для компонентов интерфейса
- **date-fns** для работы с датами

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите проект в режиме разработки:
```bash
npm run dev
```

3. Откройте [http://localhost:5173](http://localhost:5173) в браузере

## Особенности реализации

### Агрегация данных
- Данные агрегируются в реальном времени при смене периода
- Поддержка группировки по дням, неделям (пн-вс) и месяцам
- Автоматический расчет итогов

### Интерфейс
- Адаптивная таблица с горизонтальной прокруткой
- Выделение итоговой строки
- Удобный выпадающий список для выбора периода

### Данные
- 20 пользователей с русскими именами
- Случайные часы работы за последние 60 дней
- Реалистичное распределение рабочего времени (0-12 часов в день)
